# FocusFuel
Study productivity app built with Blazor (Server, .NET 8), C# and hand-written CSS (no CSS frameworks).

Purpose / Description:

FocusFuel is a productivity app that helps students stay focused using structured study timers, distraction tracking, and progress monitoring to build consistent study habits.

Target Users: College Students: Easily distracted by social media and need better time management. Board Exam Reviewees: Require structured, focused study sessions daily. Working Students: Have limited study time and must maximize productivity.

Main Functions / Features: Register – Create an account using email or student ID. Login – Secure access to personal productivity dashboard. Dashboard – Shows daily study time, active timer, and progress streaks. Profile – View total study hours, goals, and performance statistics. Logout – Securely exit the app. Smart Study Timer – Customizable Pomodoro-style timer with break reminders. Distraction Tracker – Logs interrupted sessions and identifies patterns. Goal Setting System – Set daily/weekly study targets with progress tracking. Achievement Badges – Rewards consistency and milestone completion.
